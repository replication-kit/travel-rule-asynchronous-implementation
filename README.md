# Implementation Gaps, Channel Substitution, and Hysteresis in Crypto-Asset Regulation

This repository contains the Python code used for the numerical verification and figures in the paper:

**“Implementation Gaps, Channel Substitution, and Hysteresis in Crypto-Asset Regulation”**

The revised model studies a representative cross-border crypto-asset corridor connecting two jurisdictions. Transactions are allocated across three mutually exclusive channels—compliant VASPs, weak or non-compliant VASPs, and P2P transactions—through a generalized-cost discrete-choice framework. P2P maturity evolves as a stock through prior channel use. The code verifies the analytical results and reproduces the two figures in the manuscript.

## Repository structure

- `src/verify_model.py`  
  Numerical verification of the analytical model. It checks the unique- versus multiple-equilibrium conditions, stability of the post-implementation equilibria, the basin-boundary result, the transitional hysteresis example, leader-versus-laggard comparative statics, and a no-hysteresis benchmark.

- `src/fig1.py`  
  Generates Figure 1, showing synchronized and asynchronous implementation histories and their long-run equilibrium selection. Output: `Fig1_time_paths_v2.pdf` and `Fig1_time_paths_v2.png`.

- `src/fig2.py`  
  Generates Figure 2, the post-implementation fixed-point diagram. Output: `Fig2_fixed_points.pdf` and `Fig2_fixed_points.png`.

- `requirements.txt`  
  Python package requirements.

## Requirements

Python 3.9 or later is recommended. Install the required packages with:

```bash
pip install -r requirements.txt
```

The code uses only NumPy and Matplotlib beyond the Python standard library.

## Reproducing the results

From the repository root, run:

```bash
python src/verify_model.py
python src/fig1.py
python src/fig2.py
```

`verify_model.py` prints the numerical checks reported in the manuscript. Under the baseline illustrative parameterization, it reproduces three post-implementation equilibria, with the low- and high-P2P equilibria locally stable and the intermediate equilibrium unstable. It also verifies that the two illustrative implementation histories end the transition on opposite sides of the unstable maturity threshold. The no-hysteresis benchmark lowers the P2P reinforcement parameter so that the post-implementation equilibrium is unique.

The figure scripts save PDF and PNG files in the `src/` directory.

## Reproducibility and scope

The numerical exercises are illustrative and are not calibrated to a particular jurisdiction or dataset. Their purpose is to verify the analytical parameter regions and reproduce the equilibrium-selection mechanism discussed in the paper.

No external data are used. All reported numerical results are generated by the code in this repository.
